Readme file for: "ReLAC: Measuring and Eliminating the Leakage of Revoked Access in Learned Access Control for Cloud Environments"

ESM_1_ReLAC_reproduce_all_executed.ipynb
    Jupyter notebook that downloads and verifies the benchmark data (SHA-256) and reproduces every
    number, table and figure of the article, with the outputs of the reported run.

ESM_2_ReLAC_results.zip
    All results of the reported run: per-split results (62 files), all 1,240 scenario-remedy rows,
    family means (Table S1), Wilcoxon signed-rank tests with Holm correction (Table S2),
    summary.json, paper_numbers.txt, environment.json, Figs. 2-6 (PNG, PDF) and a data dictionary.

ESM_3_ReLAC_data.zip
    Data sources, licences and SHA-256 checksums of all 22 input files; the HP Labs RBAC benchmarks
    (MIT licence) and the 15 RBAC request sets used in the experiments. The Amazon Employee Access
    and DLBAC synthetic datasets are not redistributed (no licence); the notebook downloads them
    from their original repository at a fixed commit.

The same material, with the source code, is available in the public repository given in the
Data availability statement.
